Preprocessing: preparing data for a model

Learning outcomes
  • Explain why preprocessing choices affect model behavior.
  • Compare filling missing values, dropping rows, and removing duplicates.
  • Recognize outlier sensitivity, feature-scale issues, and leakage.
  • Justify a preprocessing choice in ML-Tutor.

1. What preprocessing is

Preprocessing transforms or filters data before model training. Its purpose is not to make data look perfect; it is to make choices explicit, handle known problems, and preserve information needed for a fair evaluation.

2. Missing data and missingness

A blank may occur because a value was not measured, was not recorded, or does not apply. Those reasons matter: replacing a value is an assumption, while dropping a row reduces the available evidence.

3. Fill with an average or remove rows?

Mean imputation keeps observations but can hide uncertainty and reduce variation. Dropping rows avoids invented values but can shrink a small dataset or change which people or cases remain. In ML-Tutor, Fill Missing Values → Use Average computes numeric feature means from training data and uses those means for both feature splits. It fills a numeric training target with its mean, or a categorical target with its training mode.

Fill Missing Values → Remove Rows drops incomplete rows separately from training and test partitions. It is not a claim that one strategy is universally better.

4. Why mean can be sensitive to outliers

A mean uses every value, so an extreme value can shift it substantially. The median is often less sensitive to a single extreme value, but median imputation is a conceptual extension, not a current node control.

5. Duplicate observations

Exact duplicates can give repeated evidence more influence. They may be accidental copies, or they may represent genuinely repeated events; inspect the context before removing them.

6. Feature scales and KNN

Distance-based methods such as K-nearest neighbors are sensitive to numerical scale. A feature measured in thousands can dominate one measured from 0 to 1. Scaling is important to consider, but scaling is a conceptual extension: this Preprocessing node does not currently offer a scaling control.

7. Split first, then learn preprocessing statistics

Statistics such as a mean should be learned from training data, then applied to test data. Learning them from all rows lets held-out information influence training and is a form of data leakage. The current average strategy follows this training-first pattern for numeric feature means.

8. Applying this in ML-Tutor

The node provides only two methods: Fill Missing Values (average or remove rows) and Remove Duplicate Rows. Duplicate removal is currently applied to the training partition only, using feature values and target together; held-out test rows are not deduplicated by this operation.

Ask: What is missing? Would deletion remove important cases? Could an extreme value distort a mean? Are repeated rows meaningful? Which future transformations must be learned only from training data?

9. Check your reasoning

  1. What evidence supports my missing-data strategy?
  2. What information might I lose by dropping rows?
  3. Could duplicates be meaningful rather than accidental?
  4. What operation is not available here but may matter for my algorithm?
