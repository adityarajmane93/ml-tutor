Evaluation: interpreting model evidence

Learning outcomes
  • EV-01–03 Explain held-out evaluation, errors, and confusion matrices.
  • EV-04–07 interpret accuracy, precision, recall, F1, and averaging.
  • EV-08–10 compare baselines and justify next steps.

1. Why evaluate?

Evaluation uses held-out observations to test generalization. Training accuracy alone cannot establish model quality. Strong test performance is evidence about similar data collected under comparable conditions, not proof of universal reliability. The Dataset node’s test-size setting determines the held-out portion.

2. Predictions and errors

For a student Pass/Fail classifier, compare an actual outcome with a predicted outcome. A correct prediction matches; an error does not. The positive class depends on the task: when identifying students who may fail, Fail may be positive.

3. Confusion matrix

Rows are actual classes and columns are predicted classes. True positives and true negatives are correct; false positives and false negatives are different error types.

4. Accuracy and class imbalance

Accuracy is correct predictions divided by all predictions. It treats error types equally and can hide class-specific performance. In imbalanced data, compare it with a majority-class baseline.

5. Precision and recall

Precision asks: of predicted positives, how many were positive? Recall asks: of actual positives, how many were found? A support system may care strongly about missed students; a notification filter may weigh false alarms differently.

6. F1

F1 is the harmonic mean of precision and recall. It is high only when both are reasonably strong and, in its binary positive-class form, does not directly use true negatives. It is not universally superior to accuracy.

7. Binary and averaged metrics

Per-class metrics describe each class. Macro averaging gives classes equal influence; weighted averaging uses actual class support; micro aggregates decisions. Weighted recall equals accuracy for ordinary single-label classification, but weighted F1 is not generally the harmonic mean of weighted precision and recall.

8. Comparing models and baselines

Compare a model with Zero-R, class distribution, important-class errors, task goals, and evaluation-data suitability. Two models can have similar accuracy but different errors; the preferred model depends on context.

9. Applying evaluation in ML-Tutor

Connect Model to Evaluation, run the workflow, then select Accuracy, Precision, Recall, or F1. The node reports test-data metrics: Accuracy is shown as an integer percentage; Precision, Recall, and F1 are weighted averages rounded to two decimals. It reports aggregate metrics, not a confusion matrix. The Learn widgets are instructional simulations, not your model results.
