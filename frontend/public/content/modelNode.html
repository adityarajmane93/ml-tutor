Classification models: learning from labeled examples

Learning outcomes
  • MD-01–02 Explain supervised training, prediction, and generalization.
  • MD-03–06 Compare four classifiers, parameters, boundaries, and probabilities.
  • MD-07–09 reason about limits, fit, and algorithm choice.

1. How do models learn?

Rule-based software follows rules written in advance. A supervised model learns a relationship from labeled training observations: features → training → learned model → prediction. Training is not prediction, and finding a pattern does not imply human-like understanding or guaranteed correctness.

2. K-Nearest Neighbors

KNN compares an observation with nearby training observations and uses majority voting. K is the number of neighbors. Changing K can change the local vote; scaling and irrelevant features can change distances.

3. Decision Trees

A tree splits observations using feature-based rules. Internal nodes are questions and leaves assign a class. Maximum depth limits complexity: a deeper tree can represent more detailed rules, but may adapt too closely to training data.

4. Logistic Regression

Logistic Regression combines weighted features and turns the result into a probability between 0 and 1. A threshold maps probability to a class, creating a linear decision boundary. A probability is not a guarantee that the prediction is correct.

5. Zero-R and baselines

Zero-R predicts the most frequent training class and ignores features. With 80 Class A and 20 Class B observations, it can achieve 80% accuracy without identifying the minority class. A baseline helps judge whether a richer model adds value.

7. Fit and generalization

Underfitting can miss relevant patterns. Overfitting can adapt excessively to training examples. Training accuracy alone is insufficient: evaluate on held-out data. K and maximum depth affect complexity, but neither a larger nor smaller value is always best.

The Model node offers KNN (K defaults to 5), Decision Tree (maximum depth defaults to 3), Logistic Regression, and Zero-R. Connect a model after prior operations and compare outcomes in Evaluation. Logistic Regression and Zero-R have no learner-adjustable node parameter.
