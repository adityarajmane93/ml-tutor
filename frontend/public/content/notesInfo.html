Learn and Study Notes

Learning outcomes
  • NI-01–07 navigate, highlight, save, retrieve, and delete notes.
  • NI-08–09 distinguish copying from explaining and record questions or decisions.

1. The Learn and Notes system

Learn has three areas: a navigation panel, reading and interactive content, and the Study Notes panel. You can switch chapters while constructing or revising a workflow.

Navigation → Reading content → Study Notes

2. Highlighting important information

Select text in the reading area, review the temporary selection in Study Notes, optionally add an explanation, then save. Highlights can span formatted text and multiple paragraphs. Selecting text alone does not save a permanent note.

3. Writing useful annotations

A highlight can preserve a definition; an annotation can restate it, ask a question, record an observation, or explain a decision. For example: “Changing K can change the predicted class in KNN.” An annotation might say, “I will compare K = 3 and K = 7 because included neighbors may change.” This gives context beyond copying.

4. Standalone notes

You can save a note without selecting text. Examples: “I changed maximum depth from 3 to 5,” “accuracy rose but minority recall fell,” or “I need to check missing values.” These are observations or questions, not guaranteed conclusions.

5. Reviewing saved notes

Chapter notes appear in Study Notes. All Notes gathers notes from the current session; selecting an anchored note returns to its highlighted passage. Standalone notes have no passage to return to. Delete unwanted notes using their delete button.

6. Notes during revision

Observation → Question → Decision → Re-evaluation can organize a workflow revision. A changed model does not guarantee improvement; use results as evidence to compare attempts.

7. Quick reference

  1. Open Learn and choose a chapter.
  2. Select text, write an annotation if useful, and save.
  3. Write a standalone note when no passage is needed.
  4. Open All Notes to review or return to a passage.
  5. Delete a note you no longer want.

8. Try it in ML-Tutor

Optionally open Model Learn, highlight one concept, add a short question or explanation, save it, then open All Notes and select it to revisit the passage.
