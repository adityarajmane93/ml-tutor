Edges: dependencies in an ML workflow

Learning outcomes
  • ED-01–03 explain nodes, edges, dataflow, and sequence.
  • ED-04–07 identify valid dependencies and diagnose workflow problems.
  • ED-08–10 revise and justify a workflow.

1. Nodes and edges

A node represents an operation; an edge is a directed dependency between operations. Dataset, Preprocessing, Model, and Evaluation form a directed graph. An edge itself does not transform data or train a model.

2. Understanding dataflow

An introductory sequence is Dataset → Preprocessing → Model → Evaluation: select data, transform it, fit a model, then compare predictions with held-out labels. This is a conceptual flow, not a guarantee that every visual connection can execute.

3. Why execution order matters

Evaluation requires a trained model; a model requires prepared data. Arbitrarily reversing stages violates dependencies. Select the target before supervised training.

4. Connecting nodes

Drag from a source handle to a target handle in the workspace. Select and delete an edge to remove it. The simulator uses the introductory forward dependencies; it does not change your pipeline.

5. Diagnosing workflow errors

Structural errors include missing Dataset or Model nodes and disconnected Evaluation. Configuration errors include missing features or an invalid target. Data and execution errors may remain even when edges look complete.

6. Branching and alternatives

The execution engine can evaluate multiple incoming models, but prepares each model using its first upstream parent path. Treat branching as an advanced comparison and prefer separate executions when you need unambiguous preprocessing alternatives.

7. Revision

Construct → Execute → Inspect → Revise → Re-execute. Poor recall may motivate a revision, but does not by itself prove which node or connection caused it.

8. Applying this in ML-Tutor

Create required nodes, connect forward dependencies, choose valid settings, run the workflow, inspect results, then revise deliberately. A visually complete graph does not guarantee suitable data or reliable performance.
