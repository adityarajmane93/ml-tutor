# Learn curriculum specification

## Dataset learning outcomes

DS-01 through DS-08 address supervised-learning datasets, features and targets, task types, data quality and distribution, train/test evaluation, leakage, and justified Dataset-node choices.

## Verified alignment

- CBSE Academic publishes AI curriculum resources and a Computational Thinking and AI framework. This chapter is supporting material; it claims no unverified CBSE code or prescribed unit.
- AI4K12’s Big Idea 3 is Learning. The chapter supports reasoning about examples, labels, prediction, and evaluation without claiming a grade-band statement.
- UNESCO’s framework includes AI techniques/applications and AI system design across Understand, Apply, and Create. This chapter supports foundational Understand/Apply work without asserting an individual code.
- Train/test and leakage explanations follow scikit-learn’s `train_test_split` documentation and its common-pitfalls guidance.

## Content standards

Use semantic headings, tables, lists, and inline emphasis. Prefer worked examples, clear distinction between association and causation, explicitly labelled simulations, and explanation prompts. Preserve stable reading blocks for the Learn anchor system.
